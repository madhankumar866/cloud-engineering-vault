# Kubernetes & Kubestronaut Reference Links

A curated list of official documentation, interactive curriculum maps, and security frameworks supporting the Kubestronaut study journey.

## 🌟 Kubestronaut Program & Interactive Graphs
- **[KodeKloud Kubestronaut Knowledge Graph](https://kubestronaut.kodekloud.com/)**: Interactive visual mapping showing topic overlaps across CKA, CKAD, CKS, KCNA, and KCSA.
- **[CNCF Kubestronaut Program Overview](https://www.cncf.io/training/kubestronaut/)**: Official rules, rewards, and directory of engineers holding all 5 certifications.
- **[KodeKloud Kubestronaut Leaderboard & Cohort](https://leaderboard.kodekloud.com)**: Community tracking and 2025 cohort study goals.

## 📜 Official Exam Guides & Certification Resources
- **[CNCF Exam Curriculum Repository](https://github.com/cncf/curriculum)**: Official GitHub repo containing updated syllabus outlines for CKA, CKAD, CKS, KCNA, and KCSA.
- **[Linux Foundation Training & Certification Portal](https://training.linuxfoundation.org/certification/)**: Registration, handbook, and exam environment (Killer.sh simulation) access.
- **[Kubernetes Documentation (Exam Permitted Resource)](https://kubernetes.io/docs/home/)**: Primary bookmark target for CKA, CKAD, and CKS open-book practical exams.
- **[Kubernetes Website & Docs Upstream Repo (`kubernetes/website`)](https://github.com/kubernetes/website)**: Official source repository powering kubernetes.io. The `content/en/examples/` directory is a goldmine of canonical, exam-tested YAML manifests for Pods, Deployments, NetworkPolicies, and RBAC resources.
- **[Kubernetes Gateway API Specification](https://gateway-api.sigs.k8s.io/)**: Modern networking traffic management architecture (replacing/augmenting standard Ingress).

## 🔒 Cloud Native Security & Hardening Tooling (CKS / KCSA)
- **[CIS Kubernetes Benchmarks](https://www.cisecurity.org/benchmark/kubernetes)**: Prescriptive guidance for establishing a secure configuration posture for Kubernetes.
- **[Aqua Security Kube-bench](https://github.com/aquasecurity/kube-bench)**: Tool that runs CIS benchmark compliance checks against Kubernetes clusters.
- **[Trivy Vulnerability Scanner](https://github.com/aquasecurity/trivy)**: Comprehensive scanner for vulnerabilities in container images, file systems, and Git registries.
- **[Falco Cloud Native Runtime Security](https://falco.org/docs/)**: De facto open-source intrusion detection runtime security engine powered by eBPF.
- **[Open Policy Agent (OPA) Gatekeeper](https://open-policy-agent.github.io/gatekeeper/website/docs/)**: Custom admission controller for policy-based Kubernetes governance.
- **[Sigstore & Cosign](https://docs.sigstore.dev/cosign/overview/)**: Container signing, verification, and Software Bill of Materials (SBOM) provenance validation.

## 🛠️ Local Environments & GitOps Automation
- **[Kind (Kubernetes IN Docker)](https://kind.sigs.k8s.io/)**: Lightweight local multi-node cluster provisioning for rapid debugging and CI testing.
- **[ArgoCD Documentation](https://argo-cd.readthedocs.io/en/stable/)**: Declarative, GitOps continuous delivery tool for Kubernetes.
- **[Istio Service Mesh Documentation](https://istio.io/latest/docs/)**: Traffic governance, observability, and mTLS security zero-trust networking layer.
- **[NotHarshhaa Kubernetes Projects Repository](https://github.com/NotHarshhaa/kubernetes-projects-learning)**: Practical open-source reference implementations and hands-on learning labs.

## ⚡ Offline Documentation & Terminal Fast-Search (`kdoc` & `kyaml`)
To eliminate internet latency and simulate air-gapped secure environments during exam study, this vault provides an automated sparse shallow clone of the English documentation and canonical YAML examples (`~/.local/share/k8s-offline-docs`) paired with custom Golang systems tooling and Zsh shortcuts:
- **Automated Bootstrap Script**: [setup_k8s_offline_docs.sh](file:///Users/mk/Documents/01_Active_Work/GitHub/Cloud-Engineering-Vault/Knowledge%20Base/Kubernetes/scripts/setup_k8s_offline_docs.sh) — pulls only `content/en/docs` and `content/en/examples` via Git sparse checkout (< 40MB disk footprint without vault Git bloat).
- **Golang Systems Search Tool (`kdoc`)**: [kdoc.go](file:///Users/mk/Documents/01_Active_Work/GitHub/Cloud-Engineering-Vault/Knowledge%20Base/Kubernetes/scripts/kdoc.go) — concurrent multi-threaded regex search across tutorials and manifest inspection.
  - `kdoc search <regex>`: Searches all official Markdown concepts and YAML syntax examples in milliseconds.
  - `kdoc yaml <keyword>`: Finds and formats canonical exam YAML templates (e.g., `kdoc yaml netpol` or `kdoc yaml pv`).
  - `kdoc list <kind>`: Lists all official manifest templates matching a specific Resource Kind (e.g., `kdoc list NetworkPolicy` or `kdoc list DaemonSet`).
- **Zsh Terminal Shortcuts**:
  - `alias kdoc="rg -n --color=always -S ~/.local/share/k8s-offline-docs/content/en/"` (Fast line-numbered ripgrep search)
  - `alias kyaml="find ~/.local/share/k8s-offline-docs/content/en/examples -name '*.yaml' | fzf --preview 'cat {}'"` (Interactive fuzzy manifest finder with preview)
