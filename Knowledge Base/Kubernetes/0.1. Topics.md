# Kubestronaut Knowledge Graph & Topic Index

This is the master topic index and curriculum roadmap for achieving **Kubestronaut** status by mastering the CNCF & Linux Foundation certification tracks, derived from the [KodeKloud Kubestronaut Knowledge Graph](https://kubestronaut.kodekloud.com/). 

To become a Kubestronaut, engineers must hold all **5 active certifications**:
1. [[1. KCNA - Cloud Native Associate|KCNA (Kubernetes and Cloud Native Associate)]]
2. [[2. CKA - Kubernetes Administrator|CKA (Certified Kubernetes Administrator)]]
3. [[3. CKAD - Application Developer|CKAD (Certified Kubernetes Application Developer)]]
4. [[4. KCSA - Security Associate|KCSA (Kubernetes and Cloud Native Security Associate)]]
5. [[5. CKS - Security Specialist|CKS (Certified Kubernetes Security Specialist)]]

## 🌐 Shared Knowledge Intersect (Core Overlaps)

The power of the Kubestronaut curriculum is understanding how foundational tools, networking models, and security primitives interconnect across certification tracks:

| Topic / Technology | KCNA | CKA | CKAD | KCSA | CKS | Core Use Case / Architectural Role |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| **RBAC & Service Accounts** | 🟢 | 🟢 | 🟢 | 🟢 | 🟢 | Least-privilege API authentication and role authorization across workloads |

| **Security Contexts** | 🟢 | 🟢 | 🟢 | 🟢 | 🟢 | Linux capability restrictions, non-root user enforcement, filesystem read-only |

## 📋 Course Curricula & Study Checklists

### 1. [[1. KCNA - Cloud Native Associate|KCNA: Cloud Native Associate]]
- [ ] **Kubernetes Fundamentals:** Cloud Native concept, Containers, Orchestration, Architecture, CRI, Docker vs ContainerD
- [ ] **Kubernetes Resources:** Pods, ReplicaSets, Deployments, Rolling Updates/Rollbacks, Imperative vs Declarative, `kubectl apply`, Namespaces
- [ ] **Scheduling:** Labels/Selectors, Taints/Tolerations, Node Selectors/Affinity, Resource Quotas/Limits, DaemonSets, Static Pods, Multiple Schedulers, Scheduler Profiles
- [ ] **Security:** Security Primitives, Authentication, KubeConfig, API Groups, RBAC, ClusterRoles, ServiceAccounts, Image Security, Security Contexts, Network Policies
- [ ] **Networking:** Cluster & Pod Networking, CNI, Weave, CoreDNS, Ingress
- [ ] **Service Mesh:** Services, Sidecar Pattern, Envoy Proxy, Monoliths vs Microservices, Istio
- [ ] **Storage:** Docker Storage & Plugins, CSI, Volumes, PVs, PVCs, Storage Classes
- [ ] **Cloud Native Architecture:** Autoscaling (HPA, VPA), Serverless, KEP (Enhancement Proposals), SIGs, Open Standards
- [ ] **Cloud Native Observability:** Falco, SLO / SLA / SLI engineering, Prometheus, Cost Management (FinOps)
- [ ] **Cloud Native Application Delivery:** Delivery Fundamentals, GitOps principles, Push vs Pull deploy models, CI/CD with GitOps, ArgoCD

### 2. [[2. CKA - Kubernetes Administrator|CKA: Certified Kubernetes Administrator]]
- [ ] **Core Concepts:** Architecture, Docker vs ContainerD, etcd, API Server, Controller Manager, Scheduler, Kubelet, Kube-proxy, Extension Interfaces (CRI/CSI), Pods & YAML, ReplicaSets, Deployments, Services (ClusterIP/LoadBalancer), Namespaces, Declarative management
- [ ] **Scheduling:** Manual Scheduling, Labels & Selectors, Taints & Tolerations vs Node Affinity, Resource Quotas & Limits, DaemonSets, Static Pods, Scheduler Profiles
- [ ] **Logging & Monitoring:** Monitor Cluster Components (Metrics Server), Managing Container/App Logs
- [ ] **Application Lifecycle Management:** Rolling Updates & Rollbacks, Commands/Arguments, Env Vars, ConfigMaps, Secrets, Autoscaling (HPA, VPA, Cluster Autoscaler, KEDA Event-Driven), Liveness/Readiness Probes, Multi-Container Pod Design Patterns (Sidecar/Adapter/Ambassador), Init Containers
- [ ] **Cluster Maintenance:** OS Upgrades, Kubernetes Versioning, Kubeadm Cluster Upgrade, etcd Backup & Restore (`etcdctl snapshot`)
- [ ] **Security:** Authentication & TLS Basics/PKI in K8s, KubeConfig, API Groups, RBAC & ClusterRoles, Service Accounts, Docker & Image Security, Security Contexts, Network Policies, Validating & Mutating Admission Controllers, kubectx & kubens
- [ ] **Storage:** Docker Volume Plugins, PVs, PVCs in Pods, Storage Classes, Dynamic Provisioning
- [ ] **Networking:** Switching/Routing/Gateways in K8s, CoreDNS, Network Namespaces, CNI & Weave IPAM, Ingress, Gateway API Resource Model (Gateway, HTTPRoute, Traffic Switching)
- [ ] **Install & Configuration:** Infrastructure Setup, HA Kubeadm Cluster Init, Helm Installation & Concepts, Kustomize vs Helm (Transformers, Patches, Overlays, Components), CRDs & Operator Framework
- [ ] **Troubleshooting:** Control Plane Failure, Worker Node Failure, Application Failures, Services & DNS/Networking Troubleshooting

### 3. [[3. CKAD - Application Developer|CKAD: Certified Kubernetes Application Developer]]
- [ ] **Core Concepts:** Container Runtime, Pods, ReplicaSets, Deployments, Namespaces, Imperative creation speed-run
- [ ] **Configuration:** Docker Images, Commands & Arguments, Environment Variables, ConfigMaps, Secrets, Security Contexts, Resource Limits & Quotas, Service Accounts, Pod Scheduling constraints (Affinity/Tolerations)
- [ ] **Multi-Container Pods:** Multi-container design patterns, Init Containers
- [ ] **Observability:** Readiness & Liveness Probes, Container Logs inspection, Application debugging
- [ ] **Pod Design:** Labels & Selectors, Rolling Updates, Blue-Green & Canary Deployment Strategies, Kustomize Overlays & Components, Jobs & CronJobs
- [ ] **Services & Networking:** ClusterIP/NodePort/LoadBalancer Services, Network Policies, Ingress rules and TLS termination
- [ ] **State Persistence:** Volume mounts, Persistent Volume Claims (PVC), Storage Classes, StatefulSets, Headless Services (`ClusterIP: None`)
- [ ] **Security & Extendability:** Authentication & RBAC rules for apps, Admission Controllers, API Versions & Deprecations, Custom Resource Definitions (CRD), Custom Controllers & Operators
- [ ] **Helm Package Management:** Helm Overview, Chart anatomy, Values templating, Customizing Chart parameters, Application Lifecycle management with Helm

### 4. [[4. KCSA - Security Associate|KCSA: Cloud Native Security Associate]]
- [ ] **Overview of Cloud Native Security:** 4Cs of Security (Cloud, Cluster, Container, Code), Cloud Provider Security, Infrastructure Security, Kubernetes Isolation Techniques, Artifact & Repository Security, Image Security, Workload Code Security
- [ ] **Kubernetes Cluster Component Security:** Securing API Server, Controller Manager, Scheduler, Kubelet, CRI, Kube-proxy, etcd encryption at rest/in transit, Container Networking isolation, Kubectl Proxy & Port Forward exposure, KubeConfig permissions
- [ ] **Kubernetes Security Fundamentals:** Pod Security, Authentication vs Authorization, RBAC design, Secrets management, Namespaces & Tenant isolation, Resource Quotas, Security Contexts, Audit Logging configuration, Network Policies
- [ ] **Kubernetes Threat Model:** Trust Boundaries & Data Flows, Attack Vectors: Persistence, Denial of Service (DoS), Malicious Code Execution, Compromised Containers, Network Sniffing/Man-in-the-Middle, Sensitive Data Exfiltration, Privilege Escalation
- [ ] **Platform Security:** Minimizing Base Image Footprint (Distroless/Chainguard), Vulnerability Scanning with Trivy, Falco Runtime Threat Detection, Istio mTLS, PKI & TLS administration, Admission Controllers
- [ ] **Compliance and Security Frameworks:** Compliance Standards (CIS, SOC2, PCI-DSS, NIST), Threat Modelling Frameworks (STRIDE, MITRE ATT&CK for Kubernetes), Supply Chain Compliance (SLSA, SBOM), Automation & DevSecOps Tooling

### 5. [[5. CKS - Security Specialist|CKS: Certified Kubernetes Security Specialist]] *(Prereq: CKA)*
- [ ] **Understanding Attack Surface:** Advanced mapping of the 4Cs, threat landscape identification
- [ ] **Cluster Setup and Hardening:** CIS Kubernetes Benchmarks, running `kube-bench`, API Server/Kubelet hardening flags, ABAC vs RBAC audit, disabling Kubernetes Dashboard, securing platform binaries, automated upgrades, Docker/Containerd Daemon hardening, Restricting Cloud Node Metadata (IMDSv2 / IAM block), Endpoint Security, API Server Audit Policy profiling
- [ ] **System Hardening:** Least Privilege Principle, Minimizing host OS footprint, SSH & IAM access limits, disabling obsolete packages/ports, Linux Syscalls analysis with AquaSec Tracee, Restricting syscalls via Seccomp profiles, AppArmor profile enforcement, Linux Capabilities (`CAP_SYS_ADMIN` stripping), SELinux mandatory access controls
- [ ] **Minimize Microservice Vulnerabilities:** Pod Security Standards (PSS) & Pod Security Admission (PSA - Enforce/Audit/Warn), Open Policy Agent (OPA Gatekeeper / Rego policies), Container Sandboxing (gVisor / Kata Containers / RuntimeClasses), mTLS, Multi-Tenant Control Plane Isolation, API Priority & Fairness, Cilium eBPF network hardening
- [ ] **Supply Chain Security:** Generating & verifying Software Bill of Materials (SBOM), Static code/manifest scanning with KubeLinter, Base image footprint reduction, Image Policy Webhooks, Image Signing & Verification (Sigstore / Cosign), Automated vulnerability gating with Trivy, Artifact Repository access rules
- [ ] **Monitoring, Logging & Runtime Security:** Syscall behavioral analytics, Falco engine configuration and custom rules, Threat detection across all MITRE ATT&CK attack phases, Deep investigation of intruded containers, Mutable vs Immutable Infrastructure patterns
